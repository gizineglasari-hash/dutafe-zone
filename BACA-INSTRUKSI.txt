====================================================
FE-ZONE — PEMBARUAN 11: EDITOR KONTEN EDUKASI (PAKET C)
====================================================

APA YANG BARU DI PEMBARUAN INI?
1. MENU BARU DI PANEL ADMIN: "Editor Edukasi" 📚
   - Buka admin FE-ZONE → lihat menu baru "Editor Edukasi"
     di antara "Penilaian Video" dan "Beranda".
   - Sekarang Anda bisa mengubah isi Pojok Edukasi SENDIRI
     tanpa coding dan tanpa hubungi programmer: judul kategori,
     ikon emoji, subjudul, kartu materi, poin-poin, dan tips.
   - Ada tombol "Reset ke Bawaan" untuk mengembalikan teks
     asli kapan saja kalau hasil edit kurang cocok.
2. Perubahan langsung tampil di 3 tempat:
   - Pojok Edukasi di aplikasi peserta
   - Halaman depan (landing page) bagian "Materi Edukasi Seru"
   - Misi 7 (Share the Fe-Zone) saat peserta memilih materi
     yang mau dibagikan ke WhatsApp
3. AMAN DARI SALAH EDIT:
   - Kalau database kosong/terjadi gangguan, website otomatis
     memakai teks asli bawaan — Pojok Edukasi tidak akan pernah
     kosong.
   - Soal quiz & misi masih dikelola programmer supaya skor dan
     XP peserta tetap aman (bisa jadi paket berikutnya).

CATATAN PENTING: TIDAK ADA YANG PERLU DIAWASI DI VERCEL.
Tabel database baru dibuat OTOMATIS saat Vercel selesai build
(berkat sistem seed otomatis yang sudah ada). Tidak perlu buka
Supabase, tidak perlu SQL, tidak perlu menambah Environment
Variables.

====================================================
LANGKAH 1 — Salin file hasil unduhan ke folder proyek
====================================================
1. Buka file ZIP "fezone-pembaruan-11.zip" yang saya kirim.
2. Salin (extract) SELURUH isinya ke folder proyek:
   Downloads\Fe-zone\dutafe-zone
   - Timpa (replace) semua file lama yang ditanyakan Windows.
   - Struktur foldernya sama persis, jadi tinggal timpa.
3. File yang ikut dalam paket ini (10 file):
   - prisma/schema.prisma                          (timpa)
   - scripts/seed.production.js                    (timpa)
   - src/lib/edu-client.ts                         (baru)
   - src/app/api/content/edukasi/route.ts          (baru)
   - src/app/api/admin/edukasi/route.ts            (baru)
   - src/components/fezone/admin-edu-editor.tsx    (baru)
   - src/components/fezone/admin.tsx               (timpa)
   - src/components/fezone/edukasi.tsx             (timpa)
   - src/components/fezone/landing.tsx             (timpa)
   - src/components/fezone/mission-games.tsx       (timpa)

====================================================
LANGKAH 2 — Kirim ke GitHub (commit & push)
====================================================
1. Buka aplikasi GitHub Desktop.
2. Pastikan di bagian kiri atas repo yang dipilih adalah
   "dutafe-zone".
3. Akan terlihat banyak file berubah (sekitar 10 file).
   Di kolom "Summary" isi pesan commit:
   pembaruan 11: editor konten edukasi untuk admin
4. Tekan tombol "Commit to main".
5. Tekan tombol "Push origin".
6. Tunggu 2-3 menit — Vercel akan otomatis membangun ulang
   website (boleh dilihat di dasbor Vercel, status "Building"
   lalu "Ready").

====================================================
LANGKAH 3 — Cek hasilnya di website
====================================================
1. Buka https://dutafe-zone.vercel.app/ di browser (mode
   penyamaran/incognito agar tidak memakai login lama).
2. Masuk (login) sebagai ADMIN.
3. Lihat menu baru "Editor Edukasi" di baris menu atas.
4. Coba ubah sesuatu yang kecil dulu (mis. tips di kategori
   "Kenali Anemia"), tekan "Simpan Perubahan".
5. Buka menu Edukasi di akun peserta (atau halaman depan
   sebelum login) → perubahan harus langsung terlihat.
6. Kalau mau kembali ke teks asli: tekan "Reset ke Bawaan".
