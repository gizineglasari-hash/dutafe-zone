PAKET PEMBARUAN 5 — FE-ZONE
================================================================
Isi paket ini:
 A. FITUR "LUPA PASSWORD" VIA EMAIL (alur lengkap):
    - Halaman login peserta: tombol "Lupa password?" menuju
      halaman baru /lupa-password
    - Peserta memasukkan email -> sistem mengirim EMAIL berisi
      tombol tautan reset (berlaku 1 jam, sekali pakai)
    - Dari email, terbuka halaman /reset-password untuk membuat
      password baru, lalu masuk seperti biasa
 B. "LUPA PASSWORD ADMIN?" + PROSEDUR PEMULIHAN:
    - Halaman login admin: tautan menuju /admin/pulihkan
    - Cara A (mandiri): email admin + KODE PEMULIHAN + password
      baru (kode diatur pengelola di Vercel — langkah berikutnya)
    - Cara B (darurat): panduan hubungi pengembang program
 C. Sekalian dalam paket ini (jika belum terpasang):
    - Analisa statistik lengkap di admin (paket 4)
    - Gambar landing baru tanpa garis pinggir (paket 3)

CATATAN:
- Tabel database untuk reset password dibuat OTOMATIS saat
  deploy (tidak perlu menjalankan SQL manual apa pun).
- Sementara email belum diaktifkan, halaman lupa password akan
  menampilkan pesan "layanan email belum aktif" — ITU NORMAL.
  Aktivasi email = 1 langkah terakhir yang saya kirim setelah
  paket ini terpasang.

================================================================
LANGKAH 1 — Salin file ke folder repo
1. Klik kanan zip ini -> Extract All.
2. Tekan Ctrl+A (pilih semua isi) -> Ctrl+C.
3. Buka folder:  Downloads\Fe-zone\dutafe-zone
   lalu Ctrl+V -> bila ditanya timpa, pilih YES/Replace.

LANGKAH 1.5 — HAPUS FILE LAMA YANG SENSITIF (PENTING!)
4. Masih di folder yang sama, cari file bernama:
      PERBAIKI-LOGIN-ADMIN.sql
   Jika ada -> klik kanan -> Delete (file itu berisi kunci
   password, tidak boleh ikut ke GitHub).

LANGKAH 2 — Commit & push
5. Buka GitHub Desktop -> repository "dutafe-zone".
6. Summary tulis:  pembaruan 5: lupa password via email + pemulihan admin
7. Klik "Commit to main" -> "Push origin".
8. Tunggu 1-2 menit sampai Vercel status "Ready".

LANGKAH 3 — Cek hasil
9. Buka https://dutafe-zone.vercel.app/lupa-password
   -> harus muncul halaman "Lupa Password?" dengan kolom email.
10. Buka https://dutafe-zone.vercel.app/admin/pulihkan
   -> harus muncul "Lupa Password Admin?" dengan 2 cara pemulihan.
11. Coba isi email bebas di /lupa-password -> akan muncul pesan
    "layanan email belum aktif" (normal — tunggu langkah aktivasi).

SETELAH ITU: kirim hasil langkah ini ke saya, dan saya kirimkan
LANGKAH TERAKHIR: mengaktifkan pengiriman email + kode pemulihan
(pengaturan di Vercel, sekitar 5 menit).
