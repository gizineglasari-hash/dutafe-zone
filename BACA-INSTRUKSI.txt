FE-ZONE — PEMBARUAN 10
Perbaikan Post-Test + Teks Notifikasi Test
================================================================

ISI PEMBARUAN INI (2 perbaikan):
1. PERBAIKAN POST-TEST (bug "Koneksi bermasalah"):
   Post-Test tidak bisa menyimpan jawaban — penyebabnya SATU
   query database yang salah tulis (memakai filter "tidak null"
   pada kolom yang memang tidak pernah null, sehingga server
   crash). Sudah diperbaiki. Sekarang jawaban tersimpan, nilai
   post-test muncul, dan XP diberikan.
   Pesan error juga diperjelas: kalau suatu saat server bermasalah,
   muncul pesan jelas — bukan lagi "Koneksi bermasalah" yang
   terkesan seolah internetmu yang bermasalah.
2. TEKS NOTIFIKASI TEST diubah menjadi:
   "💊 Saatnya Ingat TTD!"
   "Minggu ini kamu belum minum TTD, yuk minum sekarang!"
   (persis seperti pengingat asli, supaya peserta melihat
   bentuk notifikasi yang sebenarnya)

CARA PASANG (3 langkah):
1. Ekstrak fezone-pembaruan-10.zip
2. Buka folder hasil ekstrak -> blok SEMUA file & folder di
   dalamnya -> SALIN (Ctrl+C)
3. Buka folder proyek: Downloads\Fe-zone\dutafe-zone
   -> TEMPEL (Ctrl+V) -> "Replace/ Timpa" bila ditanya.
4. GitHub Desktop: repository "dutafe-zone" -> centang semua
   file berubah -> Summary tulis:
   pembaruan 10: perbaikan post test + teks notifikasi test
   -> "Commit to main" -> "Push origin"
5. Tunggu Vercel selesai (status Ready, 1-2 menit).
   TIDAK perlu menambah env var apa pun — kunci pembaruan 9
   tetap dipakai.

CARA MENCOBA SETELAH TERPASANG:
- Post-Test: login peserta -> buka tab Post-Test -> jawab 10
  soal -> "Kirim Jawaban!" -> nilai muncul, tidak ada lagi
  "Koneksi bermasalah". Nilai terbaik tercatat di profil &
  dashboard.
- Notifikasi test: Admin > Ringkasan > kartu Pengingat TTD ->
  "Kirim Notifikasi Test" -> di HP peserta muncul persis:
  "💊 Saatnya Ingat TTD! Minggu ini kamu belum minum TTD, yuk
  minum sekarang!"

Catatan teknis (tidak perlu dilakukan apa pun):
- Perbaikan hanya menghapus filter query yang salah + memperkuat
  pesan error. Tidak ada fitur lama yang diubah/dihapus.
- Jika sebelumnya kamu sudah mencoba post-test dan gagal, data
  jawaban lama memang tidak tersimpan (server crash sebelum
  menyimpan) — silakan kerjakan ulang post-testnya.
