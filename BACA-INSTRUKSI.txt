====================================================
FE-ZONE — PEMBARUAN 12: EDITOR SOAL (PRE/POST-TEST & KUIS)
====================================================

APA YANG BARU DI PEMBARUAN INI?
1. MENU BARU DI PANEL ADMIN: "Editor Soal" 📝
   - Buka admin FE-ZONE → menu baru "Editor Soal" di antara
     "Editor Edukasi" dan "Beranda".
   - Yang bisa diubah SENDIRI tanpa coding:
     • Pre-Test (soal pengukuran awal)
     • Post-Test (soal peningkatan pengetahuan)
     • Kuis Mission 1 (Anemia) — versi SMP & SMA
     • Kuis Mission TTD — versi SMP & SMA
     • Mitos atau Fakta (pernyataan MITOS/FAKTA, Mission 6)
     • Final Quiz Duta (Tahap 2 Duta Challenge)
   - Per soal bisa: ubah pertanyaan, ubah pilihan jawaban,
     tambah/hapus pilihan (2-6), tandai jawaban benar (klik
     huruf A/B/C/D sampai hijau), tulis pembahasan, tambah
     soal baru (maks 30), dan hapus soal.
   - Tombol "Reset ke Bawaan" mengembalikan soal asli kapan saja.
2. AMAN:
   - Penilaian TETAP dihitung server (tidak bisa diakali peserta).
   - Nilai minimal lulus tetap >=80 dan XP tetap mengikuti
     aturan program — tidak berubah.
   - Peserta yang SUDAH mengerjakan tetap menyimpan nilai
     lamanya (mengubah soal tidak mengubah nilai lama).
   - Kalau database bermasalah, otomatis pakai soal bawaan —
     kuis tidak pernah kosong/rusak.

CATATAN PENTING: TIDAK ADA YANG PERLU DIAWASI DI VERCEL.
Tabel database baru dibuat OTOMATIS saat Vercel selesai build.
Tidak perlu buka Supabase, tidak perlu SQL, tidak perlu env var.

====================================================
LANGKAH 2 — Kirim ke GitHub (commit & push)
====================================================
1. Buka aplikasi GitHub Desktop.
2. Pastikan repo yang dipilih "dutafe-zone".
3. Di kolom "Summary" isi pesan commit:
   pembaruan 12: editor soal pre/post test dan kuis untuk admin
4. Tekan "Commit to main" lalu "Push origin".
5. Tunggu 2-3 menit sampai Vercel selesai build ("Ready").

====================================================
LANGKAH 3 — Cek hasilnya di website
====================================================
1. Buka https://dutafe-zone.vercel.app/ (mode incognito).
2. Login sebagai ADMIN → menu "Editor Soal".
3. Coba uji kecil dulu: pilih "Post-Test" → ubah teks salah
   satu soal → "Simpan Perubahan".
4. Buka akun peserta → menu Post-Test → soal versi baru harus
   tampil dan bisa dikerjakan sampai muncul nilai.
5. Coba juga tab "Mitos atau Fakta" → ubah status MITOS/FAKTA
   pada satu pernyataan → mainkan Mission 6 di akun peserta.
6. Kalau mau kembali ke soal asli: "Reset ke Bawaan".
