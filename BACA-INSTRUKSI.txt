PEMBARUAN 13 — PERBAIKAN EDITOR SOAL (FE-ZONE)
=====================================================

APA MASALAHNYA?
---------------
Setelah admin menyimpan editan soal di menu "Editor Soal", saat
editor dibuka lagi yang tampil justru SOAL LAMA (bawaan), dan tanda
"✓ sudah diedit" tidak muncul — padahal editan sebenarnya SUDAH
TERSIMPAN dan SUDAH DIPAKAI PESERTA.

Penyebabnya: ada 1 baris kode yang lupa dipanggil di file penghubung.
Ibaratnya: petugas gudang lupa membawa kunci lemari arsip — setiap
kali editor bertanya "tunjukkan soal terbaru", petugas tidak bisa
membuka lemari, lalu diam-diam menunjukkan daftar lama. Isi lemari
(soal editan kamu) aman, tidak hilang.

YANG PERLU DILAKUKAN (hanya 1 file yang berubah):
------------------------------------------------
1. Buka folder project di komputer kamu:
   Downloads\Fe-zone\dutafe-zone

2. Salin file di dalam paket ini ke folder project, TIMPA file lama
   (ikuti struktur foldernya yang sama):
   src\app\api\admin\quiz\route.ts

3. Buka GitHub Desktop:
   - Pastikan 1 file berubah (route.ts)
   - Commit message: pembaruan 13: perbaikan editor soal
   - Klik "Commit to main" lalu "Push origin"
   - Tunggu 2-3 menit, Vercel otomatis memasang perbaikan.

CARA MENGECEK SETELAH TERPASANG:
--------------------------------
1. Buka website -> login admin -> menu "Editor Soal"
2. Ubah salah satu soal -> klik "Simpan Perubahan"
3. Pindah menu dulu (misal ke Beranda), lalu buka lagi "Editor Soal"
4. Sekarang yang tampil adalah soal versi BARU (bukan soal lama),
   dan bank yang sudah diedit ada tandanya ✓

CATATAN PENTING:
----------------
- Editan yang sudah pernah kamu simpan sebelumnya TIDAK HILANG.
  Semua tetap tersimpan di database dan sudah dipakai peserta.
  Setelah perbaikan terpasang, editor akan menampilkannya kembali.
- Peserta tidak terpengaruh sama sekali selama proses ini —
  nilai dan XP tetap aman dihitung oleh server.
