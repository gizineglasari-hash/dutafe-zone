================================================================
FE-ZONE — PEMBARUAN 8
Tekan Terapi TTD + Mata Password Login + No. Telepon Pendaftaran
================================================================

ISI PEMBARUAN INI (3 fitur):
1. Materi edukasi TTD: teks "Terapi (jika sudah terdiagnosis anemia)"
   diubah menjadi "konsultasikan dengan tenaga kesehatan terkait
   dosis terapi anemia" — termasuk di ringkasan materi & pembahasan
   soal quiz agar konsisten (tidak ada lagi klaim "90 hari").
2. Halaman LOGIN: tombol mata (lihat/sembunyikan password).
3. Halaman DAFTAR: kolom baru "No. Telepon / WhatsApp" (wajib,
   format 08xxxxxxxxxx, divalidasi). Nomor otomatis tampil di
   Admin > Data Peserta (kolom Telepon) dan ikut dalam ekspor
   PDF/Excel. Akun lama tetap aman (kolom baru, boleh kosong).

CARA PASANG (4 langkah):
1. Ekstrak fezone-pembaruan-8.zip
2. Buka folder hasil ekstrak -> blok/selected SEMUA file & folder
   di dalamnya -> SALIN (Ctrl+C)
3. Buka folder proyek di komputermu:
   Downloads\Fe-zone\dutafe-zone
   -> TEMPEL (Ctrl+V) -> pilih "Replace/ Timpa" bila ditanya.
   (Struktur folder sama, jadi file lama tertimpa tepat.)
4. Buka aplikasi GitHub Desktop:
   - Pastikan repository "dutafe-zone" terpilih (kiri atas)
   - Kolom kiri: centang semua file yang berubah (biasanya otomatis)
   - Kolom bawah kiri (Summary): tulis:
     pembaruan 8: teks terapi ttd + show/hide password + no telepon
   - Klik "Commit to main"
   - Klik "Push origin" (tombol atas)
5. Tunggu 1-2 menit — Vercel otomatis memasang pembaruan.
   Kolom "phone" di database dibuat OTOMATIS saat build
   (tidak perlu SQL apa pun).

CARA MENCOBA SETELAH TERPASANG:
- Materi: buka website > Edukasi > TTD > Jadwal Konsumsi
  -> poin nomor 2 berbunyi "konsultasikan dengan tenaga kesehatan..."
- Mata password: buka halaman Masuk -> ada ikon mata di kolom password
- Telepon: Daftar akun baru -> kolom "No. Telepon / WhatsApp" wajib
  diisi (coba isi salah, misal "abc" -> akan ditolak dengan pesan jelas).
  Lalu cek Admin > Data Peserta -> kolom Telepon terisi.

Catatan teknis (tidak perlu dilakukan apa pun):
- Tidak ada fitur lama yang diubah/dihapus.
- Tidak ada kredensial di dalam paket ini.
